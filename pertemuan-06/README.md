# P5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Pengembangan

- **Baseline P5:** Menyalin Folder P4 Ke P5
- Menambahkan tombol hamburger dan JavaScript untuk membuka serta menutup menu pada layar kecil. Status tombol ikut diperbarui melalui atribut `aria-expanded` dan `aria-label`.
- Menambahkan JavaScript untuk memeriksa nama, email, semester, tanggal kunjungan, jenis pesan, topik yang diminati, program studi, dan isi pesan.

- Menghubungkan `script.js` ke `index.html` agar kode interaksi tersimpan terpisah dari struktur HTML dan tampilan CSS.

## Hasil Pengujian

- Mengisi data pada formulir Kontak, lalu mengeklik tombol Kirim.

- Mengosongkan atau mengisi data dengan format yang tidak sesuai, lalu mengeklik Kirim untuk memastikan pesan kesalahan muncul.

- Mengisi seluruh data sesuai aturan, lalu mengeklik Kirim untuk memastikan pesan “Form berhasil divalidasi.” muncul.

- Mengeklik tombol hamburger pada layar kecil untuk memastikan menu navigasi dapat dibuka dan ditutup.

- Mengeklik tombol Batal untuk memastikan formulir kembali kosong dan pesan umpan balik terhapus.
