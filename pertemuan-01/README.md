# Pertemuan 01 Capaian Pembelajaran

1. konsep dasar pemrograman web
pemrograman web adalah proses membuat aplikasi yang berjalan di internet dan bisa diakses dari mana saja pake browser. jadi beda sama aplikasi desktop yang cuma bisa dijalankan di satu komputer. dengan web, banyak orang bisa akses data dan layanan yang sama bersamaan tanpa perlu install aplikasi khusus.

2. arsitektur klien peladen
klien itu program di komputer user yang minta data, sementara peladen adalah komputernya yang terima permintaan terus proses. jadi alurnya gini: user buka website di browser (klien), klien kirim permintaan ke peladen, peladen olah datanya, terus kirim hasil balik ke klien buat ditampilkan di layar user.

3. http request dan response
HTTP adalah protokol komunikasi standar yang dipakai antara klien dan peladen. Request itu permintaan yang klien kirim ke peladen, berisi info apa yang user minta. Response adalah jawaban dari peladen yang berisi halaman web atau data yang diminta user. setiap kali user ngklik atau ngisi form di website, terjadi request dan response ini.

4. html css javascript php mysql
HTML, CSS, dan JavaScript digunakan di browser user untuk bikin halaman web yang bagus dan interaktif. HTML membuat struktur halaman, CSS ngatur tampilannya, dan JavaScript bikin halaman responsif. sementara itu PHP dan MySQL ada di peladen, PHP memproses logika bisnisnya, dan MySQL nyimpen semua data di database.

5. hubungan antarteknologi
HTML, CSS, JavaScript berjalan di browser pengguna untuk tampilan dan interaksi. ketika User ngklik tombol atau nulis sesuatu, JavaScript kirim Request ke Peladen. PHP di Peladen terima request, ambil atau olah data dari MySQL, terus kirim Response balik ke Browser. Browser terus tampilkan hasilnya pake HTML dan CSS. jadi semua teknologi ini terhubung lewat HTTP dan bikin satu sistem web yang bisa digunakan.
